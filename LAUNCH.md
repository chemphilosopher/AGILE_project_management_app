## Launch Instructions

### Option 1: Double-Click (Easiest)
Simply **double-click** the `index.html` file in your file explorer. It will open in your default web browser.

### Option 2: Open with Browser
1. Right-click `index.html`
2. Select "Open with..."
3. Choose your preferred browser (Chrome, Firefox, Safari, Edge)

### Option 3: Drag and Drop
Drag the `index.html` file into an open browser window

### Option 4: Command Line
```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html

# Or use a specific browser
google-chrome index.html
firefox index.html
```

## Troubleshooting

**If nothing appears:**
- Make sure all 3 files are in the same folder:
  - `index.html`
  - `styles.css`
  - `app.js`
- Try opening in a different browser
- Check browser console (F12) for any errors

**If styles don't load:**
- Ensure `styles.css` is in the same directory as `index.html`
- Clear browser cache and refresh (Ctrl+F5 or Cmd+Shift+R)

**If buttons don't work:**
- Ensure `app.js` is in the same directory as `index.html`
- Check that JavaScript is enabled in your browser
